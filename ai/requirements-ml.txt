# ChainGuard AI Service — training/inference dependencies (Sprint AI-3)
#
# Every version here was actually installed and verified working together
# in this sandbox — not copied from Sprint AI-1's speculative placeholder
# list. Notable, deliberate departures from that earlier list:
#
# - opencv-python-headless, not opencv-python: functionally identical for
#   training/inference (no GUI window support needed, which is all the
#   non-headless build adds); avoids pulling in X11/GTK system libraries
#   this service never uses.
# - The nvidia-*-cu12 packages are required even for CPU-only training —
#   this specific torch wheel (from plain PyPI, since download.pytorch.org
#   is outside this project's network allowlist) eagerly dlopen()s CUDA
#   shared libraries at import time regardless of whether a GPU is
#   present. torch.cuda.is_available() correctly reports False on
#   GPU-less hardware once these are installed; training then runs on CPU
#   automatically (see training/train.py's device detection).
# - numpy is NOT pinned here — it's pinned once in requirements-dataset.txt
#   (bumped to 2.5.1 during this sprint specifically for compatibility
#   with scipy/opencv-python-headless below; re-verified against the full
#   Sprint AI-1 + AI-2 test suite before changing that pin).
#
# Install: pip install -r requirements.txt -r requirements-dataset.txt -r requirements-ml.txt
